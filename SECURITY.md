# Security policy

## Supported versions

| Version | Package | Supported |
|---|---|---|
| 2.x | `rtcamp/wp-primitives` | Yes |
| 1.0.x | `rtcamp/wp-framework` (the pre-rename name) | No further releases; upgrade to 2.x |

## Reporting a vulnerability

Please do not report security issues in public issues, pull requests or
discussions.

Report them privately through GitHub instead: open the repository's
**Security** tab and choose **Report a vulnerability**, or go straight to
<https://github.com/rtCamp/wp-primitives/security/advisories/new>. The report
stays visible only to you and the maintainers, and the fix, the release and
the advisory are coordinated in that same thread.

Include what you can of:

- the affected class or method and the package version;
- the impact, and the conditions an attacker needs;
- steps or a minimal proof of concept that reproduce it.

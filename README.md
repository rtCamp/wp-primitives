`wp-primitives` is a zero-dependency **Composer library** meant to be consumed by WordPress plugins and themes. It requires PHP 8.2+ and WordPress 6.5+, and has no Composer runtime dependencies.

The library provides:

- Shared base classes for WordPress objects like post types, blocks, and settings pages.
- Loaders to manage the lifecycle of these objects.
- Utility functions and traits to simplify common tasks in WordPress development.

## Quick Start

```bash
composer require rtcamp/wp-primitives
```

For more details on requirements, installation, and usage, see [Getting started](docs/getting-started.md).
